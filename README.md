# Bertoglio Music 

Este proyecto es un reproductor de música hecho con Python y Tkinter.
A medida que fui avanzando, fui agregando funciones, mejorando la interfaz y corrigiendo errores.

A este proyecto lo elegí por el simple hecho de que las otras opciones que se ofrecían no me interesaban y este lo encontré divertido y entretenido. Algunos problemas que tuve fueron a la hora de utilizar únicamente Tkinter para la interfaz visual. Yo veía que a mis compañeros les quedaba mucho más estético y, supuestamente, usaban lo mismo que yo, pero no era así. Usaban CustomTkinter, una librería que tiene muchas más opciones y un estilo más minimalista, como el que me gusta para realizar una interfaz gráfica. Después, todo lo demás lo fui aprendiendo a medida que desarrollaba el proyecto.
